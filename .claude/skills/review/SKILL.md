# review — ревью по задаче

Отвечает на **два** вопроса сразу: соответствует ли код правилам проекта и сделано ли то,
что просили. Второй вопрос — главный, и именно поэтому задачу нужно сформулировать.

Отличие от `/check`: тот проверяет только соответствие правилам и умеет чинить.
`/review` ничего не правит — его результат отчёт.

## Аргументы

**Формулировка исходной задачи** — своими словами, как её ставили:

```
/review добавить на карточку трека кнопку «в избранное» с оптимистичным обновлением
/review подключить поиск альбомов и вывести результаты вкладкой на главном
```

Область ревью — текущий дифф (`git diff HEAD` + untracked в `lib/`). Файлы, которых
правка не касается, не проверяются: ревью — про эту задачу, а не про весь проект
(для всего проекта есть `/check all`).

### Задача не указана

Спроси одной строкой: «по какой задаче ревьюить?». Ответа нет — восстанови формулировку
из диффа и **явно** напиши в отчёте, что задача восстановлена, а не задана: сверять
результат будет не с чем, и это меняет ценность вердикта.

## Что делает

Вызывает агента `flutter-reviewer`, передав ему:

- формулировку задачи дословно;
- область — текущий дифф.

Агент собирает дифф, читает релевантные правила, прогоняет `/check` по механической части,
добавляет то, что грепом не ловится (утечки, проглоченные ошибки, расхождение с задачей),
компилирует и отчитывается. Полный порядок — в `.claude/agents/flutter-reviewer.md`.

## Что ты получаешь

Отчёт с вердиктом и таблицами:

- **соответствие задаче** — всё ли сделано, нет ли лишнего, о чём не просили;
- **нарушения правил** — по разделам, с кликабельными путями;
- **изменения поведения** — особенно визуальные: их легко внести случайно;
- **`flutter analyze`** — чисто или нет;
- **необязательное** — на вердикт не влияет.

Вердикт «нужны правки» ставится, если есть хотя бы одно нарушение правил или расхождение
с задачей.

## Порядок в работе над задачей

```
код → /check (починить механику) → /review <задача> (вердикт) → правки → /review
```

`/check` дешевле и умеет чинить сам — им имеет смысл пройтись до ревью, чтобы отчёт
не состоял из отступов и цветов.
