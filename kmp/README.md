# Вино в фокусе / VinoFocus · Kotlin Multiplatform

Текущее приложение для Android и iOS, снимок исходников от 20 октября 2026.
Общая логика написана на Kotlin. Интерфейсы — Jetpack Compose и SwiftUI.
Прежняя Flutter-версия остаётся в корне этого же репозитория вместе с историей Git.

## Возможности

- Фото бутылки или полки, выбор бутылки и ручное выделение области.
- Карточка, альтернативы, эталон, история и сохранённые вина.
- Сравнение до трёх вин и подбор по блюду.
- Винный помощник, подбор ужина и работа с каталогом магазина через устройство.
- Серверное распознавание и экспериментальный полный локальный путь.
- Русский и английский языки, светлая и тёмная темы, иконки Figma v3.

Сканер по умолчанию использует `https://wines.aiweapps.com` и получает гостевой
Bearer автоматически. Ключ OpenRouter остаётся в сервисе помощника.
История, фото, черновики и разговоры хранятся на устройстве.

## Сборка

Нужны JDK 17+, Android SDK 36, Python 3.12 для Chaquopy; для iOS — macOS и Xcode.
Версии Kotlin, AGP и библиотек закреплены в `gradle/libs.versions.toml`.
Gradle Wrapper включён в репозиторий.

```sh
cd kmp
./gradlew -PWINE_ASSISTANT_BASE_URL=https://wines.aiweapps.com/assistant/ :androidApp:assembleDebug
open iosApp/iosApp.xcodeproj
```

**Для полной сборки нужны отдельные пакеты локального runtime.** Даже серверная
iOS-сборка содержит Python/правила для ручного перехода в Local. Установите пакеты
по [контракту внешних зависимостей](EXTERNAL-RUNTIME.md) до сборки. При отсутствии
пакетов это полный снимок исходников, а не самодостаточная сборка из одного Git.
Исходники приложения больше не ссылаются на соседний приватный репозиторий.

Debug Android работает без Firebase-конфигурации. Для своей аналитики добавьте
`androidApp/google-services.json` и `iosApp/iosApp/GoogleService-Info.plist` локально.
Для физического iPhone укажите свою команду подписи в
`iosApp/Configuration/Config.xcconfig` и настройте профиль в Xcode.
Сертификаты, профили и конфигурация Firebase не публикуются.

## Состав

| Путь | Назначение |
|---|---|
| `core/` | Сеть, хранилища и платформенные контракты |
| `sharedLogic/` | Сценарии, состояние, Room, модели, навигация и DI |
| `sharedUI/`, `sharedUIKit/` | Ресурсы, тема и iOS framework |
| `androidApp/`, `iosApp/` | Нативные интерфейсы |
| `integrations/ondevice_android/` | ONNX Runtime, Chaquopy, OCR и native geometry |
| `integrations/ondevice_ios/` | Core ML, Apple Vision и мост в CPython |
| `integrations/policy-source/` | Точные Python-исходники локальной логики выбора |
| `assistant_service/` | Сервер помощника; секреты только из окружения |
| `design/`, `scripts/` | Исходные иконки, ресурсы и их генерация |

`SOURCE-MANIFEST.json` содержит SHA-256 экспортированных файлов и отдельно отмечает
правки путей сборки. При переносе поведение приложения, ID, схемы базы и данные
пользователей не менялись. Исходники существующих тестов сохранены; новые тесты
при экспорте не добавлялись.

## Проверка и ограничения

На исходной версии проверены Android-сборка, iOS Simulator и сохранность старых
данных. Полный локальный прототип Android проверен на Galaxy S24, iOS — в Simulator.
При этом экспорте отдельно прошли сборки Android Debug и iOS Server для Simulator
из каталога `kmp/` с внешними runtime-пакетами. Для 691 файла приложений проверена
полнота переноса; изменения ограничены путями сборки и настройкой подписи.
Известны ошибки OCR мелкого и искривлённого текста, дубли рамок и высокая память.
Это функциональный прототип, а не независимая оценка точности или готовый релиз.
Название и иконки от 20 октября не обновляют уже установленную TestFlight-сборку.

Для ручной проверки: фото → распознавание → карточка → эталон → история → повторное
открытие; затем два вина → сравнение → блюдо → сохранение. Для Local дополнительно
проверьте отсутствие сети, отмену, следующий скан и возврат в Server.
