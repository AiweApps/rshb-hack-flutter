# Сервис винного помощника

FastAPI-сервис для мобильного приложения: разговоры, карточки вин, подбор ужина,
каталог магазинов и ограниченные задания WebView на устройстве. Каталожные JSON
содержат публичные сведения о винах и магазинах; это снимки, а не живые остатки.

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -r assistant_service/requirements.txt
uvicorn assistant_service.app:app --host 127.0.0.1 --port 18766
```

Запускайте из `kmp/`. Сначала задайте через окружение `OPENROUTER_API_KEY`,
`OPENROUTER_MODEL`, `AUTH_VERIFY_URL` и отдельный `WINE_ASSISTANT_DB`.
Для режима проверяющего прокси нужны `WINE_ASSISTANT_AUTH_MODE=trusted_proxy`
и `WINE_ASSISTANT_GATEWAY_SECRET`. Такой сервис должен слушать только loopback
за своим авторизующим прокси. Клиентский заголовок subject прокси обязан перезаписать
после проверки токена. Прямой публичный запуск без этого прокси недопустим.

Ключи не передаются мобильному приложению. Конфигурация читается только из окружения;
полный перечень — в `config.py`. Пользовательские базы не входят в Git.
По умолчанию каталог магазина запрашивается через устройство. Отдельный
`integrations/perekrestok_device_mcp/server.py` — локальный прототип USB-моста;
его конфигурация с токеном создаётся отдельно и в репозиторий не входит.
