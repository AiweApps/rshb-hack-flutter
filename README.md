# Винный сканер · AiweApps

Мобильное приложение для поиска российских вин по фотографии. Снимите бутылку
или выберите фото из галереи: приложение покажет найденные бутылки, карточку вина,
альтернативы, эталон и ссылку на «Своё вино».

[Веб-демо](https://vines.aiweapps.com/) ·
[Сервер, Docker и API](https://github.com/AiweApps/rshb-wine-scanner)

## Возможности

- Камера и выбор изображения из галереи.
- Выбор бутылки на полке и ручное выделение области.
- Сравнение с эталоном, альтернативные карточки и переход в каталог.
- История сканирований на устройстве.
- Светлая и тёмная темы, вводный экран и настройки.
- Автоматический гостевой доступ без формы регистрации и cookies.

## Быстрый запуск

Используйте **Flutter 3.44.8** с входящим в него Dart SDK. Старый Flutter 3.35
не подходит для текущих зависимостей. Для iOS нужны macOS, Xcode и CocoaPods;
для Android — Android SDK и эмулятор либо подключённое устройство.

```bash
git clone https://github.com/AiweApps/rshb-hack-flutter.git
cd rshb-hack-flutter
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter devices
flutter run --flavor prod --dart-define=FLAVOR=prod -d DEVICE_ID
```

В iOS Simulator используйте загрузку из галереи: реальной камеры там нет.
Для запуска в симуляторе не нужны сертификаты App Store. Для физического iPhone
настройте свою команду подписи в Xcode. Сертификаты и ключи в репозиторий не входят.

Сборка для iOS Simulator:

```bash
flutter build ios --simulator --debug --flavor prod --dart-define=FLAVOR=prod
```

## Подключение к API

По умолчанию приложение подключается к `https://vines.aiweapps.com`.
Адрес задаётся в `assets/flavors/prod.json` и `assets/flavors/dev.json`, поле
`API_BASE_URL`. Секретный общий ключ приложению не нужен.

1. `POST /auth/guest/token` выдаёт гостевой Bearer-токен на 24 часа.
2. Токен хранится в защищённом хранилище устройства и передаётся в
   `Authorization: Bearer …`.
3. `POST /api/recognize` принимает multipart-фото в поле `image` и, при выборе
   области, `target_roi`.
4. `GET /api/status` проверяет готовность; `GET /api/reference/<slug>.jpg`
   получает эталон с тем же Bearer.
5. После 401 приложение обновляет токен и повторяет запрос один раз.

Подробный контракт и варианты OCR — в документации
[серверного репозитория](https://github.com/AiweApps/rshb-wine-scanner).
Распознавание выполняет API; модели не загружаются на телефон. Для локальной
серверной установки доступны Docker с PP-OCRv6 и подключение к Apple Vision API.

## Архитектура

Приложение разделено по функциям; отображение, состояние и работа с данными
разнесены по слоям.

| Каталог | Назначение |
|---|---|
| `lib/features/scan/` | Съёмка, отправка фото, результат, выбор области |
| `lib/features/history/` | История сканирований |
| `lib/features/settings/`, `onboarding/` | Настройки и знакомство с приложением |
| `lib/core/services/api/`, `auth/` | HTTP-клиент и гостевая авторизация |
| `lib/core/database/` | Локальная база истории |
| `lib/di/` | Сборка зависимостей |
| `assets/flavors/` | Конфигурация окружений |

Стек: Flutter, BLoC, GoRouter, GetIt, Dio, Drift и Flutter Secure Storage.
Фото и история сохраняются на устройстве; при распознавании фото передаётся API.
Firebase Analytics/Crashlytics не инициализированы в текущей сборке: для включения
нужна отдельная настройка своего проекта Firebase.

## Разработка и выпуск

После изменений моделей выполните генерацию, затем статическую проверку:

```bash
dart run build_runner build --delete-conflicting-outputs
flutter analyze
```

Проверьте пользовательский путь: выбор фото → распознавание → карточка → эталон →
история → повторное открытие результата. Сканер может ошибаться; окончательный
выбор можно сверить с этикеткой и альтернативами.

В `ios/fastlane/` и `android/fastlane/` сохранены сценарии выпуска. Они требуют
собственных аккаунтов разработчика, идентификаторов приложений и ключей подписи.
Шаблоны переменных — `.env.sample`; реальные `.env.prod`, `.p8`, `.p12`, `.jks`
и `key.properties` игнорируются Git. Для обычного запуска через готовый API
настраивать публикацию в магазинах не требуется.
